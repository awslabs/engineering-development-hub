{% endfor %}

{% trans attr='Show only if'|safe %}Every component has a {{ attr }} option. Leave it empty to always show the field, otherwise use one of:{% endtrans %}

{{ _("Show only if") }}{{ _("The field is visible when") }}
notify_email{{ _("notify_email is checked or has a value") }}
!notify_email{{ _("notify_email is empty (or nothing is checked)") }}

queue_name=low|high{{ _("queue_name equals low or high") }}
queue_name!=low|high{{ _("queue_name is none of the listed values") }}

  • {{ _("Combine conditions with && (AND) and || (OR). AND is evaluated first and parentheses are not supported. A single | separates alternative values: queue_name=low|high.") }}
  • {{ _("Conditions can be chained: a field depending on a hidden field is hidden too.") }}
  • {{ _("Hidden fields are not required and are sent empty to your job script.") }}
  • {{ _("When you save, EDH warns you about conditions referencing an unknown field, the field itself, a non-numeric comparison, or an empty side of && / ||.") }}
