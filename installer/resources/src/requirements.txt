# pydantic 2.12.0 is the first release with official Python 3.14 support; it
# requires pydantic-core >= 2.40, which is where cp314 wheels became available.
# 2.11.x cannot be installed on 3.14 at all: pydantic-core 2.33.2 ships no
# cp314 wheel, so pip falls back to a source build and PyO3 0.24.1 refuses any
# interpreter newer than 3.13. Stay on the latest 2.12.x patch -- 2.12.1..2.12.5
# fixed genuine 3.14 regressions (None -> NoneType, typing.Union handling).

# Babel 2.17+ decoupled the pybabel CLI entry point from setuptools (upstream
# PR #1041). Our edh_installer.sh invokes `pybabel compile` via CLI — not the
# programmatic compile_catalog().run() API which still imports
# babel.messages.setuptools_frontend → setuptools. So we do not need setuptools
# as a runtime dep. Verified on fresh Python 3.13 venv: Babel 2.17.0 AND 2.18.0
# both compile all 12 catalogs cleanly with no setuptools installed.
